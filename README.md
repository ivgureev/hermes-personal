# GUREEV VECTOR · HERMES AI AGENT

Рабочий MVP-прототип личного цифрового исполнителя на Streamlit. За архитектурный референс взят Hermes Agent: единый диалоговый контур, сессии, работа с инструментами и наблюдаемое исполнение. Бизнес-поведение задано приложенным системным промтом, а UI — токенами и исходными активами GUREEV VECTOR v3.1.1.

## Возможности

- Чат с OpenAI-compatible API или безопасным демонстрационным режимом.
- Классификация риска до выполнения запроса.
- Отдельная очередь подтверждений для значимых действий.
- Реестр задач со сроками, приоритетами и статусами.
- Локальная загрузка файлов, SHA-256 и маркировка «Недоверенные данные».
- Аудит-события в SQLite и выгрузка журнала в CSV.
- Просмотр встроенного системного промта.
- Утверждённые логотип, иконка, цвета и Streamlit-тема из брендбука v3.1.1.

## Границы MVP

- Внешние действия не исполняются: подтверждение фиксирует решение пользователя, но не отправляет письмо, не удаляет файл и не совершает платёж.
- Файлы сохраняются локально, но их содержимое не извлекается и не передаётся модели автоматически.
- Нет аутентификации и разграничения ролей; MVP предназначен для локального одиночного использования.
- Интеграции с Telegram, браузером, MCP, расписаниями и субагентами не включены.
- Тёмная тема не реализована: брендбук v3.1.1 прямо запрещает её до утверждения отдельных токенов.

## Быстрый запуск

### Windows PowerShell

```powershell
cd gv-hermes-ai-agent
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:LLM_API_KEY="ВАШ_КЛЮЧ"
$env:LLM_BASE_URL="https://api.deepseek.com"
$env:LLM_MODEL="deepseek-chat"
streamlit run app.py
```

Без `LLM_API_KEY` приложение запускается в демонстрационном режиме.

### Linux / macOS

```bash
cd gv-hermes-ai-agent
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export LLM_API_KEY="ВАШ_КЛЮЧ"
export LLM_BASE_URL="https://api.deepseek.com"
export LLM_MODEL="deepseek-chat"
streamlit run app.py
```

## Проверка

```bash
python -m compileall app.py db.py llm.py risk.py styles.py
pytest -q
streamlit run app.py --server.headless true
```

Проверить вручную:

1. Запрос «Сравни два варианта» даёт ответ без подтверждения.
2. Запрос «Отправь письмо поставщику» создаёт карточку подтверждения и ничего не отправляет.
3. Загруженный файл получает SHA-256 и метку недоверенных данных.
4. Изменение задачи отражается в журнале.
5. Ключ API не отображается и не попадает в SQLite.

## Структура

```text
app.py                  Streamlit UI и пользовательские сценарии
db.py                   SQLite и аудит
llm.py                  OpenAI-compatible LLM-клиент
risk.py                 Детерминированная классификация риска
styles.py               UI-стили по токенам бренда
prompt/system_prompt.md Системный промт исполнителя
assets/                 Утверждённые активы v3.1.1
.streamlit/config.toml  Утверждённая светлая тема
tests/                  Приёмочные unit-тесты
```

## Бренд-контроль

- Полный знак используется из эталонного SVG и не набирается текстом.
- В шапке используется утверждённая квадратная иконка.
- `#08B8CC` используется только в знаке и декоре.
- Для кнопок и ссылок применяется `#057C8A`, hover — `#045C66`.
- Основной шрифт — Inter, технические данные — JetBrains Mono.
- Пользовательские документы в будущих модулях должны формироваться в нейтральном режиме без знака и слов GUREEV VECTOR.
